# WS-005: Derived stats engine (suggestive)

## Description

The app stores correct data but doesn't derive stats from it. Equipped armor doesn't affect AC (G19), class features don't modify saves/speed/AC (G6/G7/G20), attack bonus isn't computed (G23), resources aren't auto-created from class features (G11).

Critical design principle: **all derived values are suggestions, not enforcements**. Use the existing "auto: +5" pattern (already used for Prof Bonus). Every auto-calculated field shows the computed value as a default but the player can override it. Homebrew rules always win.

## Acceptance Criteria

- [ ] AC auto-calculated from equipped armor + DEX + shield + class features — editable override
- [ ] Attack bonus auto-calculated from ability mod + proficiency — editable override
- [ ] Save proficiencies suggested from class — toggleable, not locked
- [ ] Speed suggested from race + class features — editable override
- [ ] Resources auto-created from class features (e.g., Ki Points, Sorcery Points) — deletable
- [ ] All auto-calculated fields show "auto" indicator and allow manual override
- [ ] Overridden values persist and don't get clobbered by recalculation
- [ ] Works correctly for multiclass characters (highest unarmored defense, combined features)
