# WS-008: Level-up flow for multiclass

## Description

Guided level-up flow (Phase 8 from FUTURE.md). Pick class (multiclass option), roll or take average HP, select new features (subclass at 3, ASI/feat at 4/8/12/16/19, spells), auto-update derived stats, show diff of what changed.

Suggestive, not restrictive: suggest multiclass prerequisites but don't enforce them. Player can level into any class. Suggest average HP but allow any value.

## Acceptance Criteria

- [ ] Level-up button on character sheet triggers guided flow
- [ ] Class picker: current class pre-selected, any class available for multiclass
- [ ] HP: suggest average (with roll option) but accept any value
- [ ] Feature selection: subclass, ASI/feat, new spells — all suggestive
- [ ] Multiclass prerequisites shown as info, not blockers
- [ ] Diff view: show what changed (new HP, new features, new spell slots, stat changes)
- [ ] Derived stats auto-update after level-up (uses WS-005 engine)
- [ ] Can level up multiple times in sequence
- [ ] Undo/revert last level-up option
