# WS-007: DM dashboard view

## Description

A single-page DM view that shows quick reference stats for all party members. The DM opens this in one browser window/tab while running the game. Shows the info a DM needs to glance at mid-combat or mid-session without asking players.

Not a full character sheet — a compact reference panel per player.

## Acceptance Criteria

- [ ] Route: `/dm` or `/dm/:partyId`
- [ ] Shows all characters in a party/campaign as compact cards
- [ ] Per-character card shows: name, class/level, HP (current/max), AC, conditions, initiative, passive perception, spell slots (used/total), key saves
- [ ] Cards update in real-time or near-real-time (PocketBase subscriptions or polling)
- [ ] DM can click a character card to expand for more detail (or link to full sheet)
- [ ] Party selection: pick characters by name or create a "party" grouping
- [ ] Mobile-friendly — usable on a tablet at the game table
- [ ] Read-only by default — DM doesn't accidentally edit player sheets
