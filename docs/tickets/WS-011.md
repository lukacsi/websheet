# WS-011: Combat page with action economy and class features

## Description

Add a combat-focused view/page that shows everything a player needs mid-combat: available actions (Attack, Dodge, Dash, Disengage, Help, Hide, Ready, Use Object), bonus actions, reactions, and class-specific combat features. Currently the sheet has HP/AC/conditions but no action economy tracking or feature quick-reference.

Suggestive, not restrictive — show standard actions but allow custom ones. Class features should surface relevant combat abilities (e.g., Sneak Attack, Action Surge, Rage, Smite) without hiding anything.

## Acceptance Criteria

- [ ] Combat section/page shows standard actions (Attack, Cast a Spell, Dash, Disengage, Dodge, Help, Hide, Ready, Use Object)
- [ ] Bonus action section with class-specific bonus actions surfaced from features
- [ ] Reaction section (Opportunity Attack + class-specific like Shield, Counterspell)
- [ ] Class combat features displayed as quick-reference cards (e.g., Sneak Attack dice, Rage damage bonus, Smite slots)
- [ ] Action/bonus/reaction used toggles per round (reset on "Next Turn" or round advance)
- [ ] Movement tracker (speed - distance used)
- [ ] Works with existing HP, AC, conditions, and death saves
- [ ] Custom actions addable (homebrew)
- [ ] Mobile-friendly layout

**Decision:** Hybrid approach for combat feature references — auto-suggest via keyword matching (attack, damage, reaction, bonus action, AC, hit points) + player pins/unpins. New `pinnedCombatFeatures: string[]` on Character. Same pattern for spells (auto-surface reaction/bonus action spells).

## Notes

Standard 5e action economy: 1 action + 1 bonus action + 1 reaction + movement per turn. Some features grant extra actions (Action Surge, Haste). Class features from `class_features` PB collection should be filtered for combat-relevant ones.
