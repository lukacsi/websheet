# WS-010: Suggestive-not-restrictive audit

## Description

Core design principle: the app suggests 5e rules but never enforces them. Homebrew always wins. Every auto-calculated field must be overridable, every choice must be skippable, no validation should block non-RAW values.

Audit the entire app for enforcement patterns and convert them to suggestions.

## Acceptance Criteria

- [ ] All NumberInput fields accept any value (no min/max that blocks homebrew)
- [ ] All Select/picker fields allow custom/freeform entry where possible
- [ ] Auto-calculated values (AC, attack bonus, saves, HP) use "auto: X" pattern with override
- [ ] Overridden values persist and don't get reset on recalculation
- [ ] Wizard validation is minimal: only require name, everything else optional/skippable
- [ ] Level-up suggestions are informational, not blocking (e.g., multiclass prereqs shown but not enforced)
- [ ] Class/race/background pickers don't filter out "invalid" combinations
- [ ] isHomebrew flag available on all entity types
- [ ] Spell level restrictions shown as warnings, not blocks (a Fighter can have a spell if the DM says so)
