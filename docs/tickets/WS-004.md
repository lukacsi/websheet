# WS-004: Wizard multi-level choice support

## Description

The creation wizard handles Level 1 choices but ignores choices at higher levels: ASIs/feats (G3), Eldritch Invocations (G16), Fighting Styles (G24), Pact Boons (G18), Oath Spells (G22), starting equipment alternatives (G4). These are all "choose from list" patterns at specific class levels.

Remember: suggest choices but don't enforce them. Players should be able to pick non-RAW options or skip choices entirely (homebrew).

## Acceptance Criteria

- [ ] ASI/feat choice offered at appropriate levels (4, 8, 12, 16, 19) — skippable
- [ ] Warlock invocation choices offered at level 2+ — any invocation selectable, not just "valid" ones
- [ ] Fighter/Ranger/Paladin fighting style choices offered — all styles available regardless of class
- [ ] Warlock pact boon offered at level 3
- [ ] Oath/Domain/Circle spell lists shown as suggestions (not auto-added)
- [ ] All choices are suggestions — player can override, skip, or enter custom values
- [ ] Choices persist on save and display on character sheet
